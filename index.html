About

I'm an Atlassian Administrator in Baku, working day to day with Atlassian products such as Jira Service Management, Jira, Confluence, Bitbucket, Crowd across Cloud and Data Center. My focus is making the platform do exactly what a team needs — through configuration first, scripting where configuration runs out, and plugin development where scripting does too.

That ranges from ScriptRunner/Groovy validators, scripted fields, and behaviours, to Assets/Insight data modelling, REST API integrations, and a custom JSM portal plugin (Java/P2) built from the SDK up. Underneath it I own the platform itself — administering Jira on Ubuntu Linux, running version upgrades, querying the PostgreSQL backend directly for reporting, and migrating Confluence spaces between Cloud and Data Center.

I work fluently in English and Russian, often delivering bilingual configurations and documentation. I'm currently open to remote opportunities.

A Java/P2 plugin for JSM Data Center 9.4.3 that lets reporters edit their own requests from the customer portal. Built from the Atlassian Plugin SDK: custom web panel, ISO 8601 date handling, AUI datepicker fixes, mandatory reason field, and forced-public comment visibility.
